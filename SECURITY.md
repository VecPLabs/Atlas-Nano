# Security policy

Atlas Nano is research-preview software and should not be used as the sole
security or safety control for a production system.

Please report suspected vulnerabilities privately to david@vecplabs.com. Include
the affected version, model profile, runtime, reproduction steps, and potential
impact. Do not attach harmful datasets, credentials, private model artifacts, or
personal data unless a secure transfer method has been agreed upon.

Public issues are appropriate for non-sensitive bugs and documentation problems.
No response-time or remediation SLA is currently offered.
