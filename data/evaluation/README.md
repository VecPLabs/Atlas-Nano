# Candidate evaluation data

These files are retained for reproducibility but are not a locked held-out test
set and are not bundled in the Python wheel.

- `gauntlet_TEST_enhanced.txt` mixes Atlas-authored prompts with OR-Bench-Hard-1K
  material.
- `gauntlet_HARMBENCH_CLEANED.txt` contains HarmBench and related benchmark
  material identified by row prefixes.

Do not describe results on these files as independent held-out performance.
Review [../../DATA_LICENSES.md](../../DATA_LICENSES.md) before redistribution.
